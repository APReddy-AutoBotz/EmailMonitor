# EmailMonitor

Academic contact discovery and extraction for multiple organizations.

The planned core workflow accepts a keyword plus an approved publisher/source, or a search-results, article, or PDF URL; follows relevant search results and pagination; and extracts article metadata, author roles, professional email addresses, affiliations, and source evidence.

## Repository status

Documentation preparation baseline, 2026-10-08. No application has been implemented or deployed. Live extraction coverage, performance, and commercial source permissions have not been validated.

Email outreach, reply classification, and manuscript handling are later phases, not prerequisites for the extraction product.

This repository is public. Do not commit credentials, customer information, harvested contacts, licensed articles, or production exports.
