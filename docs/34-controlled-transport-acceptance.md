## Transport boundary

`ProtectedGateway` obtains immutable server-composed scope and current-policy callbacks. It authorizes before DNS, queries both complete A/AAAA families, rejects any non-public/mixed/unsupported answer set, selects exactly one literal in the trusted requested family, and reauthorizes before actual TCP. It never uses OS name service, proxy/environment headers, retries, alternate peers, cookies or client body/method controls. HTTPS port is always 443; actual socket peers are compared with the selected literal before and after TLS. TLS requires CA and hostname validation with the original hostname as SNI. The bounded response framing parser rejects duplicate/ambiguous headers and transfer encoding; HTML bytes are capped at 32 KiB in this acceptance assembly. Redirects preserve the original absolute deadline, authorize the new URL before fresh DNS and maintain bounded history. Current policy is rechecked before byte release.

The acceptance resolver uses connected UDP to the immutable synthetic authority on port 5353 with unpredictable query IDs. Its bounded 512-byte authoritative A/AAAA grammar accepts exact questions, full owner names or only the question pointer, and no aliases, truncation, extra records, cache or recursive fallback. Unsupported DNS forms fail closed. This is an actual selected-destination resolver/transport exercised on synthetic hosts; it is not activation of an unrestricted live recursive resolver or publisher connector.

Untrusted browser code remains in the previously verified network-none container. It receives only bounded byte mediation; it cannot choose the tenant scope, DNS route, literal family, CA, credentials or connection options. The trusted gateway has a separate constrained networked container. Its stage callbacks cross owned bounded pipes to the host's actual current PostgreSQL tenant/source authorization; session/database credentials never enter the gateway or fixture containers. The host verifies every callback's exact organization/source/version/operation/host/deadline/redirect scope and again checks current policy before releasing bytes to the browser.
